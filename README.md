# 日の出・日の入りレポート

市区町村名または郵便番号で地点を探し、日付を選ぶと、日の出・南中・日の入り・昼の長さ（日本時間）を表示する Web ページです。選んだ地点は都道府県名つきで、簡略化した日本地図の上に示します。地図には、その時点の昼夜（昼は明るく、夜は暗く）と、日の出・日の入りの線を重ね、地点のいまの天気・気温・風向・風速も出します。太陽の通り道の図、前日との昼の長さの差、その月の毎日の一覧も出し、CSV で保存できます。

## 使い方

1. `index.html` をブラウザで開く（インストール不要）
2. 地名（例：`札幌市`、`横浜市中区`）か郵便番号（例：`100-0001`）を入れて「検索」を押し、候補から地点を選ぶ
3. 日付を選ぶ（はじめは今日）。「‹」「›」で1日ずつ動かせ、月の表の日付を押してもその日に切り替わる
4. 「CSV で保存」で、その月の一覧を保存できる（Excel で開ける形）

## 知っておくこと

- 地名の検索には、国土地理院の地名検索 API を使います。**入力した地名はこの API へ送られます**（このアプリは保存しません）。日本国内だけが対象です
- 郵便番号の検索では、郵便番号から住所を調べるために **zipcloud**（zipcloud.ibsnet.co.jp）へ郵便番号が送られ、得た住所の座標を国土地理院で調べます（保存はしません）
- 天気は **Open-Meteo**（api.open-meteo.com）から取得します。**選んだ地点の緯度・経度（小数2桁に丸めたもの）が送られます**（保存はしません）。値は気象観測そのものではなく、気象モデルによる現在の値です。Open-Meteo は非商用の利用が無料です
- 地図の昼夜と線は、選んだ日付に、いまの時計の時刻（日本時間）を合わせた瞬間のものです。今日を選べば、いまの昼夜になります（通信はしません）
- 日本地図は、Natural Earth（パブリックドメイン）の海岸線を単純化して、このアプリの中に入れた図です（実行時に外部の地図は読み込みません）。位置は目安です
- 時刻は NOAA の計算式による計算値です。国立天文台の暦とは ±1 分で合うことを確かめています。標高や山などの地形は考えていません
- インターネットにつながっていないときは、検索ができません（計算そのものは通信しません）
